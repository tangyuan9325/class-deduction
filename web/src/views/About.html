部署步骤（三选一）
方式一 · 一键运行（推荐）
克隆后进入目录，执行 go build -o class-deduction ./cmd，再运行 ./class-deduction，浏览器访问 http://localhost:8080。
方式二 · 前端二次开发
进入 web 目录执行 npm install && npm run dev，前端源码在 web/src，每个模块均已拆分为独立的 html / css / js 文件。
方式三 · 自动部署（GitHub Actions）
推送代码到 main 分支即自动构建、测试并产出 Linux 可执行文件；配置服务器密钥后还可自动部署到你的服务器。
