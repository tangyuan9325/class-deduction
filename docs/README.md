# 班级量化考核管理系统 · GitHub Pages 在线版（v1.3.0）

在线地址：`https://tangyuan9325.github.io/class-deduction/`

## 这是什么

本项目是一个「班级量化考核管理系统」的静态在线版，采用 **GitHub 仓库即数据库** 方案（v1.3.0 起数据库拆分多文件）：
前端页面通过 GitHub API + Token 读写本仓库 `docs/data/` 下的多个数据文件，实现跨设备持久化与多端实时同步（Pages CDN + raw 源站双通道轮询，不消耗 API 配额）。

## v1.3.0 功能更新公告（2026-09-09）

- **学科老师账号**：新增全部学科老师账号（语文/数学/英语/物理/化学/技术/地理/历史/生物/政治老师，共 10 位；首次登录强制修改密码），拥有权限：录入加分、学习类扣分、班级看板。
- **看板账号更名**：「kandban」→「看板」，可查看扣分明细（含原因/备注），密码支持自助修改。
- **扣分明细展示**：看板及所有可查看扣分记录的账号，记录列表全面显示具体原因（含备注），无备注显示「无备注」。
- **类别新增「其它」**：所有扣分/加分类别的小项新增「其它」（如 学习—其它），选「其它」时必须填写备注原因；非「其它」项备注可不填，显示为「无备注」。
- **数据库拆分重构**（优化效率）：
  - `docs/data/accounts.json` —— 账号控制库（用户/角色/权限/性别/已读日志）
  - `docs/data/records.json` —— 扣分/加分记录库 + 操作审计日志
  - `docs/data/feedback.json` —— 意见反馈库
  - `docs/data/users/<账号>/pwd.json` —— 每用户独立密码文件（PBKDF2 加密）
- **暂存-递交更新**：拥有权限的用户修改加/减分或账号内容时，先暂存于浏览器（可连续操作多笔），确认后点击右下角「递交更新」统一写入云端；暂存内容在刷新/重开页面后仍保留。
- **性别修复**：按 2706 班名单修复全部 44 名学生性别（女 9 / 男 35）。
- **效率优化**：实时同步改双通道（CDN+raw）不消耗 API 配额；本地缓存秒开；写入按域拆分更小更快。
- **数据保障**：升级前已备份 v4 数据库（`docs/data/backup/db.v4.backup.json`），全部 47 个既有账号、扣分/加分记录完整保留。

## 数据存储与安全说明

⚠️ **重要**：本在线版为演示 / 校内使用设计。页面中的写令牌以混淆形式存在于前端源码，任何访问者均可通过开发者工具提取（与经典「换座位」项目同一模式）。**请勿**在真实敏感生产环境使用此方案；生产环境请使用仓库内的 Go 后端（Gin + SQLite + JWT）。

- 数据目录：`docs/data/`（多文件拆分，见上）
- 写令牌：`docs/gh-token.js`（运行时还原，混淆存储，最小权限）
- 实时同步：CDN + raw 双通道轮询（页面隐藏自动暂停）
- 密码：PBKDF2 + 随机盐 + 60 万次迭代

## 本地部署

```bash
git clone https://github.com/tangyuan9325/class-deduction.git
# 在线版：直接打开 docs/index.html 或使用任意静态服务器托管 docs 目录
# 本地完整版（含 Go 后端）：
cd class-deduction
go build -o class-deduction ./cmd && ./class-deduction
# 浏览器访问 http://localhost:8080
```
