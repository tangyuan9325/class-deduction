# 班级量化考核管理系统 · GitHub Pages 在线版（v1.2.0）

在线地址：`https://tangyuan9325.github.io/class-deduction/`

## 这是什么

本项目是一个「班级量化考核管理系统」的静态在线版，采用 **GitHub 仓库即数据库** 方案：
前端页面通过 GitHub API + Token 读写本仓库 `docs/data/db.json`，实现跨设备持久化与多端实时同步（CDN 8 秒 / API 30 秒自适应轮询，页面隐藏自动暂停）。

## v1.2.0 修复与更新公告（2026-09-06）

### 🔐 安全升级
- **密码体系重构**：登录密码由「SHA-256 直接哈希」升级为 **PBKDF2 + 随机盐 + 60 万次迭代** 的高强度加密存储，修复「哈希即密码」高危漏洞——即使数据库泄露，也无法还原明文密码或直接利用哈希登录。
- **旧账号自动升级**：原有账号首次登录时自动升级为新加密格式，无需重新注册。
- **敏感操作二次验证**：新建/删除用户、重置密码、修改权限等高风险操作，需再次输入当前密码确认。
- **操作审计日志**：所有写入操作（登录升级、录分、撤销、用户管理、反馈等）自动记录审计日志（最多保留 500 条）。

### ⚡ 性能与稳定性
- **API 配额优化**：引入 ETag/304 缓存，数据未变化时 API 请求不消耗配额；轮询频率自适应（前台 8s/30s，后台暂停），配额消耗降低约 90%。
- **多端并发防覆盖**：写入改为「读-合并-写 + 409 冲突重试」，记录级合并，多端同时操作不再互相覆盖、不丢数据。

### 🛠 安全修复
- 修复 CSV 导出公式注入（`=+-@` 前缀转义）。
- 修复个别页面 XSS 隐患（列表/排行渲染转义）。

### 📱 体验优化
- **移动端适配**：新增汉堡菜单 + 抽屉式导航、触控友好控件、窄屏排版优化。
- **桌面端优化**：内容区自适应居中、表格/卡片间距微调。

### 🗄 数据保障
- 升级前已对 v3 数据库完整备份（`docs/data/backup/db.v3.backup.json`），升级过程不丢任何扣分/加分/用户数据。

## 数据存储与安全说明

⚠️ **重要**：本在线版为演示 / 校内使用设计。页面中的写令牌以混淆形式存在于前端源码，任何访问者均可通过开发者工具提取（与经典「换座位」项目同一模式）。**请勿**在真实敏感生产环境使用此方案；生产环境请使用仓库内的 Go 后端（Gin + SQLite + JWT）。

- 数据文件：`docs/data/db.json`
- 写令牌：`docs/gh-token.js`（运行时还原，混淆存储）
- 实时同步：CDN 8 秒 / API 30 秒自适应轮询（ETag 缓存，页面隐藏暂停）

## 本地部署

```bash
git clone https://github.com/tangyuan9325/class-deduction.git
# 在线版：直接打开 docs/index.html 或使用任意静态服务器托管 docs 目录
# 本地完整版（含 Go 后端）：
cd class-deduction
go build -o class-deduction ./cmd && ./class-deduction
# 浏览器访问 http://localhost:8080
```
