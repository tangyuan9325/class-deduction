# 班级量化考核 · 在线版 v1.4.20261111

在线地址：`https://tangyuan9325.github.io/class-deduction/`

## 这是什么

一个跑在 GitHub Pages 上的班级量化考核系统，没有后端服务器。页面把数据读写到本仓库的 `docs/data/`，因此换设备、换浏览器都能看到同一份记录：

| 文件 | 内容 |
|---|---|
| `docs/data/accounts.json` | 账号、角色、权限、已读版本 |
| `docs/data/records.json` | 扣分与加分记录 + 操作审计 |
| `docs/data/feedback.json` | 意见反馈 |
| `docs/data/users/<账号>/pwd.json` | 每个账号独立的密码记录 |

读取走 Pages CDN 与 raw 源站双通道，不消耗 API 配额；写入走 GitHub Contents API，每次提交都在仓库历史里留痕。

## v1.4 更新（2026-11-11）

- **写令牌加密**：仓库里不再有可用的明文凭据，`docs/gh-token.js` 存的是 AES-256-GCM 密文，密钥由「写入口令」经 PBKDF2-SHA256 60 万次派生。没有口令只能浏览，不能录入。
- **页面重做**：记分册方向（纸与墨），宋体标题、线性图标、表格化数字，去掉渐变、发光、彩色阴影与表情符号；看板改为一张近 14 天净分主图表。
- **修复递交提示**：原来无论递交几项都提示「共 0 项」。
- **修复并发覆盖**：写入前重新读取远端并做字段合并，两个老师同时改账号不会再互相覆盖。
- **修复同步打断输入**：轮询不再每 10 秒重绘当前页面；正在输入或打开弹窗时只提示「有新的记录」。
- **修复越权导出**（Go 后端）：`/api/v1/export/records` 补上「查看扣分记录」校验。
- **修复录入校验**（Go 后端）：类别白名单、分值符号与范围、目标必须是学生、日期不得晚于今天。
- **修复目录穿越**（Go 后端静态服务）：规范化路径并限制在静态根目录内。
- **口令策略**：新密码至少 8 位（纯数字 10 位），拒绝常见口令；登录失败统一提示，不再暴露账号是否存在。
- **临时密码**：重置密码改为随机一次性密码，不再统一重置为 `123456`。
- **CSP**：加内容安全策略，限制脚本来源，降低令牌被注入脚本窃取的风险。
- **递交通道检测**：登录页与侧栏底部显示 GitHub 是否可达，直接判断当前网络能否递交扣分；不可达时给出「只能查看」的说明，可点「重测」。断网、切换网络、回到页面时自动复检。
- **侧边栏折叠**：桌面端可把侧栏收成 64px 图标条，状态记在本机；手机上仍用抽屉。
- **页面过渡**：切换页面时内容淡出淡入并轻微上移，遵循「减少动效」系统设置。
- **学生写入**：在用户管理里被勾选了录入类别的学生账号，现在可以正常解锁并录入；此前只认管理员与老师，会出现「能看到录入菜单却提示无权限」。
- **历史备份清理**：`docs/data/backup/db.v3.backup.json` 中已废弃的无盐 SHA-256 口令散列已清空，其余数据保留。

## 写入权限怎么用

写入口令不存放在仓库里，由管理员保管。在页面上：

1. 用有录入权限的账号登录（管理员、老师，或在用户管理里勾选了类别的学生）；
2. 点侧栏底部「解锁写入」，输入口令；
3. 解锁状态只存在当前标签页，关掉浏览器即失效；点「写入已解锁」可以手动锁定。

录入、撤销、改账号、提交反馈都需要先解锁。口令错误时无法解密，也不会留下任何痕迹。

### 更换令牌或口令

在本机执行（需要 Node 18 以上）：

```bash
node tools/make-token.mjs <新的 GitHub 令牌> <新的写入口令> docs/gh-token.js
```

然后把生成的 `docs/gh-token.js` 提交。也可以在页面「关于与部署 → 更换写令牌或口令」里生成同名文件，再手动替换提交。

令牌建议使用 **Fine-grained token**，只勾选本仓库的 `Contents: Read and write`，并设置有效期。

## 安全边界（请如实理解）

这是一个纯静态站点，没有服务器，因此：

- **登录只是界面隔离，不是安全边界。** 浏览器里的一切判断都能被本机改掉。真正的门槛是写入口令：没有它就拿不到令牌，也就写不进仓库。
- **只读数据是公开的。** 仓库是公开的，`docs/data/records.json` 里含学生姓名与扣分事由，`accounts.json` 里含账号。任何拿到仓库地址的人都能读到。如果这份数据需要保密，请改用带后端的自建部署，把数据放在服务器上。
- 密码使用 PBKDF2-SHA256 + 随机盐 + 60 万次迭代，泄露哈希不等于泄露密码，但弱口令仍可能被猜解。

## 本地预览

```bash
# 任意静态服务器指向 docs 目录即可
python3 -m http.server 8080 --directory docs
```

写入功能需要 GitHub API，本地预览时同样要解锁。

## 完整版（自带后端）

仓库同时保留 Go + Gin + SQLite 的完整实现，数据存本机，适合校内自建：

```bash
go build -o class-deduction ./cmd && ./class-deduction
# 访问 http://localhost:8080
```

首次启动会创建 `admin` / `banzhuren` / `kandban` 三个账号，**初始密码只用于首次登录，登录后强制修改**。

## 页面

- 班级看板：累计扣分、加分、净分、记录数，近 14 天净分图，类别分布，最近记录，两个 TOP5
- 周与学期小结：班级或个人，生成一段可直接发给家长的文字，可导出 CSV
- 同学扣分汇总：每日 / 每周 / 每月，按扣分排序，可导出
- 录入扣分 / 录入加分：按类别与项目批量录入，先暂存再统一递交
- 扣分记录：类别与关键词筛选、分页、导出、撤销
- 个人统计：本人全部记录
- 意见反馈：老师提交与处理；学生可通过 GitHub Issues 留言
- 用户管理：新建学生、分配权限、重置密码
- 关于与部署：版本说明、克隆命令、存储与安全说明
